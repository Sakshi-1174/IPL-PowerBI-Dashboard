# IPL Analysis Dashboard | Power BI

## About the Project
This project focuses on analyzing IPL match and player performance using Power BI. It provides insights into batting, bowling, team performance, venues, and match statistics through interactive visualizations.

## Dashboard Pages
The dashboard includes the following sections:

1. **Overview** – Overall IPL statistics and key performance indicators.
2. **Batter Analysis** – Analysis of batter performance and statistics.
3. **Bowler Analysis** – Insights into bowling performance.
4. **Team Analysis** – Comparison of team performance.
5. **Venue Analysis** – Analysis of match statistics across different venues.
6. **Match Analysis** – Match-wise performance and statistics.
7. **Records & Milestones** – Important IPL records and milestones.
8. **Report Summary** – Summary of key insights from the dashboard.
